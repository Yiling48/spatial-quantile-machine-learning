# Simulation Experiments

This folder is reserved for the cleaned simulation scripts used to compare the proposed geographically weighted tree-based quantile models with benchmark methods.

Planned contents include:
- data-generating processes,
- repeated simulation loops,
- bandwidth / hyperparameter settings,
- Pinball Loss and Pseudo R² summaries,
- residual spatial-autocorrelation evaluation.

The original thesis workspace contains experiment-specific scripts that still need to be separated from local paths and intermediate outputs before public release.
